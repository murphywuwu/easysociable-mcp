# MCP-first

Use the unified EasySociable MCP for Template authoring, images, icons, Profiles,
Themes and Render Jobs. Fall back to the equivalent `easysociable` CLI command
only when MCP is unavailable.

Neither path may call Local API, SQLite, Directus, R2, Stripe, private Template
Service or a third-party provider through EasySociable. Host-installed image
MCPs are optional discovery tools and are never auto-installed.
