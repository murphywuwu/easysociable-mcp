# Platform page caps

The Run validates only the actual `content-pack.v1.pages.length`. There is no
`designMax`, full-page deck skeleton, or deck catalog to clone.

| platform | hardMin | hardMax | default canvas |
|---|---:|---:|---|
| tiktok | 4 | 35 | 9:16 · 1080×1920 |
| instagram | 2 | 20 | 4:5 · 1080×1350 |
| linkedin | 2 | 300 | 1:1 · 1080×1080 |
| x | 2 | 4 | platform-specific X organic image size |
| xiaohongshu | 2 | 18 | platform-specific vertical image size |
| threads | 2 | 20 | platform-specific image size |

If a pack is outside the cap, stop before creating a Run and ask the agent to
revise the page count or split the piece. Never silently drop a CTA or pad a
pack to a product skeleton.
